# Дослідження операцій

Статичний сайт із матеріалами курсу «Дослідження операцій» (ФКНК, КНУ імені
Тараса Шевченка). Без збірки і без залежностей — лише HTML і один файл CSS.

## Структура

```
index.html         про курс, викладачі, перелік розділів
lectures.html      лекції (12, .pptx)
practice.html      практичні заняття (9, .pdf)
labs.html          лабораторні роботи (9, .pdf)
literature.html    література (.pdf)
other.html         програма курсу, шаблони, програмні засоби
404.html           сторінка «не знайдено»
css/style.css      усі стилі
materials/         сюди кладуться файли матеріалів
.nojekyll          вимикає обробку Jekyll на GitHub Pages
```

## Куди класти файли

Сторінки вже посилаються на конкретні імена файлів. Достатньо покласти файл із
таким іменем — посилання запрацює.

| Тека | Імена файлів |
|---|---|
| `materials/lectures/` | `lecture-01.pptx` … `lecture-12.pptx` |
| `materials/practice/` | `practice-01.pdf` … `practice-09.pdf` |
| `materials/labs/` | `lab-01.pdf` … `lab-09.pdf` |
| `materials/literature/` | імена див. у `literature.html` |
| `materials/other/` | `syllabus.pdf`, `report-template.docx`, `report-example.pdf`, `exam-questions.pdf` |

Номер завжди з двох цифр: `lab-03.pdf`, а не `lab-3.pdf`.

Якщо зручніше тримати власні імена файлів — не перейменовуйте їх, а виправте
адресу в атрибуті `href` відповідного рядка на сторінці.

## Як змінити список матеріалів

Кожен пункт списку — це один блок `<li>`:

```html
<li><a class="row" href="materials/labs/lab-10.pdf">
  <span class="m-num">10</span>
  <span class="m-title">Назва роботи</span>
  <span class="m-ext">pdf</span></a></li>
```

Щоб **додати** пункт — скопіюйте такий блок і змініть номер, назву та `href`.
Щоб **прибрати** — видаліть блок цілком. Щоб **перейменувати** тему — змініть
текст усередині `<span class="m-title">`.

Назви тем лекцій, практичних і лабораторних зараз узяті за типовою програмою
курсу — виправте їх під свою робочу програму.

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і залийте туди вміст цієї теки:

```bash
git init && git add . && git commit -m "Матеріали курсу" && git branch -M main && git remote add origin https://github.com/USERNAME/REPO.git && git push -u origin main
```

2. У репозиторії: **Settings → Pages**.
3. У полі **Source** оберіть **Deploy from a branch**, гілка `main`, тека `/ (root)`, натисніть **Save**.
4. Через 1–2 хвилини сайт буде за адресою `https://USERNAME.github.io/REPO/`.

Якщо назвати репозиторій `USERNAME.github.io`, адреса буде без підпапки:
`https://USERNAME.github.io/`.

**Одне уточнення для `404.html`:** посилання на головну в ньому вказані як `/`.
Якщо сайт лежить у підпапці (`USERNAME.github.io/REPO/`), замініть у цьому
файлі `href="/"` на `href="/REPO/"`. Решти сторінок це не стосується — там усі
шляхи відносні й працюють за будь-якої адреси.

## Перегляд локально

Просто відкрийте `index.html` у браузері — цього достатньо, сервер не потрібен.

## Що ще варто оновити

- Рік у підвалі кожної сторінки (`© 2026 …`).
- Список літератури в `literature.html` під фактичний перелік курсу.
